# Banana AI Windows Companion

This optional local helper allows the Banana AI website to request a very small set of approved Windows actions. The hosted website cannot otherwise control your PC.

## Safe actions
- Open Notepad
- Open Calculator
- Open Paint
- Open File Explorer
- Open a normal HTTP/HTTPS URL in the default browser

It does **not** run arbitrary commands, PowerShell scripts, downloaded files, or commands generated by an AI model.

## Start
1. Install Node.js LTS on Windows if it is not already installed.
2. From the repository root, double-click `desktop-companion/start.bat`.
3. Copy the pairing token printed in the terminal into Banana AI's Computer panel.
4. Keep the terminal running while you use the feature. Press Ctrl+C to stop it.

The helper binds only to `127.0.0.1`. It creates a local `.token` file on first run. Do not share this token or commit it. The browser asks for confirmation before each action.

The current CORS allowlist includes the production Banana AI URL and local development URLs. Preview deployment URLs are intentionally not allowed by default.

## Troubleshooting
- If the browser says it cannot connect, make sure the companion terminal is still running.
- If pairing fails, copy the full token again.
- If Windows blocks an app, open that app manually and check Windows security settings.
